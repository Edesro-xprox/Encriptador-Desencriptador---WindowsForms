# Nombre del Proyecto
Xprox Encryptor/Decryptor

Breve descripción
Aplicación Windows Forms para encriptar y desencriptar texto.

## Requisitos
- Sistema operativo: Windows
- .NET: .NET 6.0 (compilado para net6.0-windows; también hay salida para net10.0-windows)

## Tecnología / versión
- Lenguaje: C#
- Framework: .NET 6.0 / .NET 10 (Windows Forms)

## Configuración AES
- Crea un archivo appsettings.json y coloca las claves principal, IV (vector de inicialización) y maestra.
- La clave principal debe tener 32 bytes.
- La clave IV debe tener 16 bytes.
- La clave maestra puede tener cantidad de bytes variable.
